# Blockchain Glossary

A glossary provides quick definitions for commonly used blockchain and Web3 terminology.
Keeping key concepts in one place makes technical documentation easier to understand and review.
The glossary will expand gradually as new concepts are explored.

## Core Terms

### Blockchain
A distributed ledger used to record and verify data across a network of participants.

### Smart Contract
A program deployed on a blockchain that can execute predefined logic when its conditions are met.

### Wallet
A tool that allows users to manage blockchain accounts and interact with decentralized applications.

### Transaction
A signed instruction submitted to a blockchain for processing and confirmation.
## DeFi Terms

### Liquidity
The availability of assets that can be exchanged within a market without causing significant price impact.

### AMM
An automated market maker is a decentralized trading mechanism that uses liquidity pools and mathematical formulas to facilitate swaps.

### Liquidity Pool
A pool of assets supplied by users to support trading and other protocol functions.

### Slippage
The difference between the expected price of a transaction and the price at which it is actually executed.

## Network Terms

### Layer 1
The primary blockchain network responsible for processing transactions and maintaining its own security.

### Layer 2
A scaling system built on top of a Layer 1 network to improve transaction capacity and efficiency.

### Gas
A fee mechanism used to compensate the network for processing transactions and executing blockchain operations.

### Bridge
A protocol or system that enables assets or information to move between different blockchain networks.
